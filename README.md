# Summer Training: Data Science & Machine Learning

Welcome to my **Summer Training** repository! This repository serves as a centralized hub for all the coursework, practical implementations, and projects completed during my intensive training program in Data Science and Machine Learning. 

All core implementations are documented step-by-step using **Jupyter Notebooks**.

---

## 📁 Repository Structure & Projects

The repository is organized into distinct modules, tracking progression from data analysis fundamentals to advanced predictive modeling:

### 📊 Data Analysis & Visualization
* **`pandas_problem_statements.ipynb`**: Practical problem-solving and data manipulation tasks using the Pandas library.
* **`Day_3(Matplotlib_Project).ipynb`**: Exploratory data visualization using static plots and charts in Matplotlib.
* **`Day_4(Seaborn_Projects).ipynb`**: Statistical data visualization utilizing Seaborn for deeper data insights.
* **`Day_5(EDA_Project).ipynb`**: A comprehensive End-to-End Exploratory Data Analysis (EDA) on a real-world dataset to uncover patterns and anomalies.

### 🤖 Machine Learning & Predictions
* **`Stock Market Trend Prediction`**: Machine learning models applied to historical financial data to forecast stock trends.
* **`Wether Temperature Prediction`**: Predictive modeling built to analyze meteorological data and forecast temperature variations.

### 📈 Business Intelligence
* **`PowerBI`**: Interactive dashboards and data visualization reports built to translate raw data into actionable business insights.

### 🧮 Utility Tools
* **`Calculator_project.ipynb`**: A foundational Python project implementing core mathematical operations.

---

## 🛠️ Tech Stack & Tools

* **Programming Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
* **Tools & Platforms:** Jupyter Notebook, Power BI, GitHub
